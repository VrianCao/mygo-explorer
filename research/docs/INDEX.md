## Relevance tags

| Tag | Meaning for the showcase app |
|---|---|
| **core** | Required reading/API to build the gallery (programming model, layout, theme, every control, navigation, overlays, testing, app shell, packaging). |
| **useful** | Needed for parts of the app or for quality/profiling (inspector, rendering, performance, browsers, heavy `ui/*` packages, desktop APIs, CI). |
| **peripheral** | Not needed for a native-UI gallery: web-frontend-only features (bindings, frontend, JS plugins), documents, launchers, audio, updater. |

The “Group” column of the Native UI table is exactly the sections of
`docs/ui/README.md` (the toolkit's own table of contents).

## Recommended reading order for the implementer

1. `docs/ui/README.md` (counter example + group index) → `ui/views.md` →
   `ui/layout.md` → `ui/text.md` → `ui/styling.md` → `ui/input.md`.
2. `ui/windows.md` + root `windows.md#options` (shell/window chrome) and
   `menus.md` (menu bar, accelerators, tray).
3. Per-widget pages for the screens you build (every page under
   “Actions … Images” below).
4. `ui/navigation.md`, `ui/overlays.md`, `ui/accessibility.md`,
   `ui/right-to-left.md`, `ui/testing.md`, `ui/inspector.md`,
   `ui/performance.md`, `ui/rendering.md`.
5. `i18n.md` (§ Native UI + catalogs) and `configuration.md`, `cli.md`,
   `distribution.md`, `github-actions.md` for shipping.
6. `architecture.md#platform-differences` (line 4550) before comparing OSes;
   see `PLATFORM-DIFFERENCES.md` for the synthesized analysis.
